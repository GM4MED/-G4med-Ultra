Sobre o G4med

O G4med Intelligent Health System é uma plataforma desenvolvida para clínicas, hospitais e consultórios médicos.

Seu objetivo é simplificar processos administrativos e clínicos, oferecendo maior segurança, produtividade e organização.

O sistema contempla módulos como:

  • Cadastro de Pacientes
  • Agenda Médica
  • Atendimento
  • Financeiro
  • Convênios
  • Prontuário Eletrônico
  • Relatórios
  • Auditoria
  • Gestão Administrativa

Privacidade de Dados

Todos os dados médicos são tratados conforme a Lei Geral de Proteção de Dados (LGPD).

As informações são protegidas por mecanismos de autenticação, criptografia e controle de acesso.

O sistema registra auditoria completa de alterações para garantir rastreabilidade.

Como acessar o prontuário

Para acessar o prontuário de um paciente no G4med, siga os passos:

  1. Acesse o menu Atendimento na barra lateral.
  2. Clique em Prontuário Eletrônico.
  3. Utilize a barra de pesquisa para buscar pelo nome ou CPF do paciente.
  4. Clique no nome do paciente para visualizar o histórico completo.

Você também pode acessar o prontuário diretamente pela Agenda, clicando no nome do paciente no horário agendado.

Configuração do receituário

O G4med permite configurar modelos personalizados de receituário:

  1. Acesse Utilitários > Configurações.
  2. Selecione a aba Receituário.
  3. Clique em Novo Modelo.
  4. Defina o cabeçalho, campos e assinatura digital.
  5. Salve e vincule ao perfil do médico.

Agendamento

Para criar uma nova agenda médica:

  1. Acesse o menu Agenda.
  2. Clique no botão Novo Agendamento.
  3. Selecione o paciente, médico, data e horário.
  4. Escolha o tipo de atendimento (Presencial, Online, Retorno ou Procedimento).
  5. Confirme e envie lembretes automáticos por WhatsApp/SMS.

Cadastro de Paciente

Para cadastrar um novo paciente:

  1. Acesse Cadastro > Paciente.
  2. Clique em Novo.
  3. Preencha os dados pessoais, endereço e contato.
  4. Adicione informações de convênio, se houver.
  5. Salve o cadastro.

Convênios

Gerenciamento de convênios e planos de saúde:

  1. Acesse Utilitários > Convênio.
  2. Cadastre o plano com nome, CNPJ e dados de contato.
  3. Configure tabelas de procedimentos e valores.
  4. Vincule o convênio aos pacientes no cadastro.

Relatórios

Geração e exportação de relatórios:

  1. Acesse Relatório no menu lateral.
  2. Escolha o tipo: Atendimentos, Pacientes, Financeiro ou Médico.
  3. Defina o período e filtros desejados.
  4. Visualize na tela ou exporte em PDF/Excel.
